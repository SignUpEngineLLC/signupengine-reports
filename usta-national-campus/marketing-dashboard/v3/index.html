How tracked links work
Email is automatic

With tracking switched on in Brevo, every link in an email is tagged. Just name each Brevo campaign the way this page shows.

Ads are set up once

Chad adds tracking to every Meta and Google ad at setup, so ads don't need links from here.

Copy, don't retype

Paste links exactly as created. The short link and the full link count visits the same way. A visit from a link without tags counts as "Direct and other."

One name per campaign

Use the same campaign name across email, ads, and links, such as ltt_january_early_bird, so channels can be compared side by side.
